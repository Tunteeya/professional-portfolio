# 🌐 Umar Farouk | Portfolio Website

## 📖 About the Project
This project is a **personal portfolio website** created to represent **Umar Farouk**, a passionate Software Engineering Student with a love for technology and innovation.  

The website showcases my **skills, projects, and experiences** in a clean and modern interface designed to reflect professionalism and creativity. It features sections such as **About**, **Portfolio**, **Skills**, and a **Download CV** option, giving visitors a clear view of my journey and capabilities.  

Built using **HTML**, **CSS**, and **JavaScript**, the portfolio emphasizes responsive design, simplicity, and interactivity. It serves as both an online resume and a personal branding tool for career growth and collaboration opportunities.
